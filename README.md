# RBF do Brasil — Site institucional

Proposta de site institucional da RBF do Brasil, fabricante de nobreaks, estabilizadores e transformadores.

## Preview

https://thiago-tertuliano.github.io/rbf-do-brasil/

## Stack

- Next.js 15 (export estático)
- Tailwind CSS 4
- Framer Motion
- TypeScript

## Desenvolvimento local

```bash
npm install
npm run dev
```

O site sobe em `http://localhost:3000`.

Para gerar a versão estática (a mesma que vai para o GitHub Pages):

```bash
npm run build
```

A pasta `out/` contém os arquivos prontos para publicação.
